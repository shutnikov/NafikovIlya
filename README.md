# Expense Tracker

Автор: Нафиков Илья Иванович

Описание: Простое приложение для учета личных расходов с возможностью фильтрации, подсчета и сохранения данных.

Инструкция по использованию:
- Запустить программу.
- Ввести сумму, выбрать категорию и дату, нажать "Добавить расход".
- Для фильтрации выбрать категорию или задать дату.
- Посчитать сумму за выбранный период.

Примеры:
- Добавить расход 100 рублей на еду 2024-04-25.
- Отфильтровать по категории "Транспорт" и установить период с 2024-04-01 по 2024-04-30.
