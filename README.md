## Как получить API-ключ

1. Зарегистрируйтесь на сайте [exchangerate-api.com](https://www.exchangerate-api.com).
2. Создайте аккаунт и получите API-ключ в личном кабинете.

## Использование

1. Клонируйте репозиторий.
2. Вставьте ваш API-ключ в код (в переменную `API_KEY`).
3. Запустите приложение.
4. Выберите валюты, введите сумму и нажмите "Конвертировать".
5. Просматривайте историю в таблице.

## Примеры тестов

- Конвертация из USD в EUR для суммы 100.
- Конвертация из RUB в USD для суммы 5000.
